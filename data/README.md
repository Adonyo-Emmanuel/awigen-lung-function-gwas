# Data

No individual-level data or summary statistics are distributed in this
repository. The analyses use controlled-access cohort data and large external
resources.

## AWI-Gen genotype and phenotype data

AWI-Gen data were generated by the H3Africa Consortium. They are available to
qualified researchers through application to the H3Africa Data and Biospecimen
Access Committee. The data are deposited in the European Genome-phenome
Archive (EGA) under accession **EGAS________** _(to be added)_.

## GWAS summary statistics

The meta-analysis summary statistics for FEV1, FVC, FEV1/FVC and PEF will be
deposited in the NHGRI-EBI GWAS Catalog under accession(s) **GCST________**
_(to be added on publication)_.

## External resources

The V2G pipeline uses published resources (for example eQTLGen, GTEx, UK
Biobank Olink pQTLs, Orphanet and IMPC). Download them from their original
providers, following each resource's terms of use, and point the local config
file (`pipelines/05_v2g/config/*.local.tsv`) to the local copies.
